# ServiceNow Metro Ticket Generating System

A Metro Ticket Generating System developed using ServiceNow to provide an easy and automated metro ticket booking process.

## Project Overview

This project allows users to book metro tickets by selecting the source station, destination station, journey type, and number of passengers.

The system automatically calculates the fare and generates a QR code for the booked ticket.

## Features

- Metro station and route management
- Passenger details management
- Online metro ticket booking
- Source and destination selection
- Journey type selection
- Automatic fare calculation
- Passenger count-based fare calculation
- QR code generation
- Catalog UI Policies
- Catalog Client Scripts
- Service Portal integration

## ServiceNow Technologies Used

- Service Catalog
- Catalog Items
- Variables
- Catalog Client Scripts
- Catalog UI Policies
- Service Portal
- Update Sets
- JavaScript
